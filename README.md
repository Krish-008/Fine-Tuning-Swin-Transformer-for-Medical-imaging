# Fine-Tuning-Swin-Transformer-for-Medical-imaging
In general we trained and evaluted three models on the brain tumor MRI dataset to classify images into 4 categories which are Giloma, Meningioma, Pituitary tumor and No tumor. The 3 models represent a progression from a simple baseline trained from scartch, to transfer learning with frozen backbone, to full fine tuning of the foundational swin-tiny tranformer.  

**Model 1 - Simple CNN (From scratch)**  Setup - The baseline model is a 3 layer CNN with around 94k trainable parameters. it uses 3 convolutional blocks(conv - batchNorm - ReLU - pooling). followed by global average pooling and a single linear classification head. all the weights are randomly initialized- no pretrained knowledge is used, and also the model was trained on 20 epochs using Adam and with learing rate of 1e-3 with a batch size of 32.  The simple CNN got around a 75% overall accuracy, which is well above the 25% random baseline for a 4-class problem.  Convergence: The training loss decreased stedily across all the 20 epochs, confirming the model converged. the test accuracy started going in a single line around epoch 12-15, indicating the model reached its max performance. The gap between training and test accuracy suggests mild overfitting expected given the model must learn all visual features from only 5,600 images with no prior knowledge.  We think that 75% accuracy establishes the lower bound for the task. The models capacity which is 94K means that it can detect broad discriminative pattern in the MRI scans but struggles with the very small visual difference between the tumor types 

**Model 2 - Swin-Tiny(frozen backbone).**  We loaded the swin-tiny model pretrained on the imagenet and replaced its 1k class head with a new linear(768-4) head for our tumor classes . the entire swin backbone(28.3 M parameters) was frozen - only the 3067 classification head parameters were trained. the model was trained on 15 epochs using Adam (lr = 1e-3) with pre trained features with no adaptation of the backbone to MRI data.  Convergence: The model actually converged rapidly and the test accuracy stabilized by epoch 5 and remained same till reaching 10 epochs. this is actually quite expected because with only 3076 parameters training, the optimization is small.  the 10% improvement over the baseline demonstrated the power of transfer learning - the ImageNet features generalize effectively to MRI scans despite being learned on the natural images. But from the 85% ceiling gives us a limitation: the frozen backbone cannot adapt to the MRI- specific patterns, this might not be good for subtle tumor charactersitcs in medical scans.  

**Model 3 - Swin-Tiny(Fine tuned)**  In this we completely used Swin-Tiny weights but this time we used the complete model with all the 28.3M parameters.  we used graident cliiping for stable training and AdamW optimizer with weight decay = 0.01 in. backbone. The batch size is reduced to 16 to accommodate larger gradient memory from the unfrozen layers.  Convergence: The model actually converged really smoothly ov er 15 epochs. the results were stable decreasing the loss curves without the sudden drops. The train and test gap was much smaller than the previous two models, indicating the better generalization. the adapted backbone provides representations tuned to MRI data rather than generic ImageNet features.  The 95% accuracy demonstrates the fine tuning is the most effective startegy for this dataset. by allowing the high level swin stages to adapt to brain MRI patterns while preserving low level general features.
